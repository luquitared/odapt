Multiplayer Claude Code and Codex.

Open source. Deploy it to your VM and start coding with friends or your team: everyone sees the same live agent terminals, workflows are shared and launch on cron, and your home agent manages the cloud ones over an API.

# on your VM · needs bun and tmux
git clone https://github.com/luquitared/lofiwave.git
cd lofiwave
bun start

Your agents, together

01 · shared terminals

See and drive the same agent terminals

Every Claude Code and Codex session runs as the real TUI in tmux. Anyone on the team can open it in the browser or on their phone, watch it work, and type into it. Each session shows who started it, and the header shows who's here.

claude · fix-flaky-testsMSJ
started by maya · 12 min ago
> the retry test still flakes on CI
● Reading tests/retry.test.ts
● Found it: the timer isn't faked
✓ 48 passed
> sam is typing…
02 · workflows on cron

Share workflows and launch them on a schedule

A workflow is a saved agent launch: folder, prompt, model, args. Run it by hand or on cron. Each run is a live session anyone can step into, and every run is kept with its status, duration and full log.

# workflows
nightly-review   codex   0 2 * * 1-5   ✓ 14m
triage-issues    claude  @hourly       ✓ 3m
dep-bumps        claude  0 9 * * mon   ● running
release-notes    claude  by hand       ✓ 6m
03 · an API for agents

Manage your cloud agents from your home agent

Everything in the UI is a REST call, documented at /api/docs. Make an API key on the Connect page, hand the URL to the Claude on your laptop, and it can start, watch, type into and stop the agents on your cloud box.

# from your laptop's Claude Code
curl -X POST $LOFIWAVE/api/processes \
  -H "authorization: Bearer $KEY" \
  -H "content-type: application/json" \
  -d '{"type":"claude","cwd":"~/app",
       "prompt":"ship the fix in #212"}'
# → 201 {"id": 318, "status": "running"}

Also

See every agent

Every agent process on the machine, including the ones you started in a terminal: session name, working or idle, model, and its claude.ai link.

From your phone

Put it on Tailscale and the UI adapts: a session opens full screen and its terminal resizes to the phone's width.

Remote Control

Turn on Claude Code's Remote Control for a session that is already running, and keep going in the Claude app.

Commits under your name

Map each teammate to a git identity, and the agents they start commit as them.

Small on purpose

Bun and SQLite, no other dependencies. It listens on 127.0.0.1 and asks for a token on every call, so other pages in your browser can't drive it. For a team, run it on a shared VM, set a password, and put it behind HTTPS: everyone signs in with their name. macOS and Linux; Windows is best-effort.
