lofiwave GitHub ↗

A quiet console for your coding agents.

See every Claude Code and Codex session running on your machine, start and stop them from your browser or your phone, and schedule them like cron. It runs on your own machine. Open source, MIT.

# needs bun; tmux for interactive runs
git clone https://github.com/synjuku/lofiwave.git
cd lofiwave
bun start

What it does

See every agent

Every agent process on the machine, including the ones you started in a terminal: session name, working or idle, model, and its claude.ai link.

Real terminals in the browser

Start Claude Code or Codex interactively in tmux and type into the real TUI from any browser. Several people can watch the same session.

Schedule workflows

Cron schedules that launch an agent in a folder, with a history of every run: status, exit code, duration and full logs.

From your phone

Put it on Tailscale and the UI adapts: tabs move to the bottom, and an interactive terminal resizes to the phone's width.

Remote Control

Turn on Claude Code's Remote Control for a session that is already running, and keep going in the Claude app.

An API for agents

Everything is a REST call, documented at /api/docs, so your agents can start and watch other agents.

Small on purpose

Bun and SQLite, no other dependencies. It listens on 127.0.0.1 and asks for a token on every call, so other pages in your browser can't drive it. For a team server, set a password and put it behind HTTPS. macOS and Linux; Windows is best-effort.
