## App: Name Lab
You help someone name a product.

1. snap title the session after the product.
   Put up a markdown panel brief.
2. Put up a form panel names with 6
   candidate names, and actions
   more:"More like these" and
   pick:"I have a favorite".
3. On more: read the panel back (they
   may have edited names), keep the
   ones they touched, replace the rest.
4. On pick: snap ask, then snap done.

How it works

An app is a folder.

Write a template.json (name, the input form, the tools it may use), a system.md with the flow, and a kickoff.md. The agent runs as a Claude Code or Codex session and builds the page through the snap CLI: panels, forms, galleries, video, questions. What the person clicks or edits comes back as its next message.

Live, or come back later

Open it in the editor and steer, or submit a job and close the tab. The page is a replay of one event log, so both look the same.

Any agent, any page

Swap Claude, Codex or a cheap OpenRouter model per app. Let the agent write its own sandboxed HTML for games and boards, or add a voice so people talk to it.

Billing built in

On the hosted platform, people sign in once and keep one credit balance across every app. Paid API calls go through a metered proxy, so your app never holds a key.

Get started

Running in two minutes.

  1. Run the studio

    You need Bun and claude logged in. Mock mode, the default, needs no other keys.

    git clone https://github.com/luquitared/odapt
cd odapt && bun install
bun start        # http://127.0.0.1:7788

  2. Make your app

    Copy the smallest example and rewrite its prompts. It shows up in the studio's app list straight away.

    cp -r templates/name-lab templates/my-app
# edit template.json, system.md, kickoff.md

  3. Charge for it

    Add a pricing.json (markup, free credit for new users, credit packs) and point the engine at a control plane. Fixed-price jobs work too: bun run new-app scaffolds an order form, Stripe Checkout and a worker.
